Paradigmas — Python, FastAPI y PostgreSQL

La interfaz gráfica del proyecto, en Flask, hablando por HTTP con una API en FastAPI que consulta PostgreSQL. Tres procesos, tres contenedores.

Todavía no pide identificarse, y es a propósito. El control de acceso —contraseña con hash, sesión con token, 401 y 403— es parte de esta versión y todavía no está construido: la API atiende a cualquiera que llegue al 8005.
El código del login está escrito y comentado en app.py y en las rutas, con la nota de dónde se vuelve a encender. Lo que falta no es esta pieza: es el otro lado.
